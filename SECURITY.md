# Security policy

## Reporting a vulnerability

Please do not publish passwords, cookies, session tokens, private URLs or other
sensitive account information in an issue. For security-sensitive reports,
use GitHub's private vulnerability reporting feature when it is enabled for
this repository.

## Sensitive data

VideoDL can read a user-selected browser cookie export. Cookie files can grant
access to personal accounts. Keep them private and do not attach them to issue
reports or share them with other people.

VideoDL has no application backend and does not upload cookie files to a
VideoDL-operated server. Downloads connect directly to the target website
through yt-dlp.
